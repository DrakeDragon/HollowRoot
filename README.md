# HollowRoot
 🌳 Hollowroot: Rise of the Elven Realm  **An enormous idle kingdom-builder for your phone.** Tap the World-Tree, raise a realm from a burnt glade to an Ascendant Realm, level a hero, bond with 41 creatures, conquer a 30-region map, live through an 84-chapter story, then Rebirth and Ascend to do it all again, bigger.
